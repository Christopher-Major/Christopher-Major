# 🚀 Featured Project

## 🏢 Windows Server & Active Directory Enterprise Lab

**Status: ✅ Completed & Published**

[![View Repository](https://img.shields.io/badge/View%20Project-GitHub-181717?style=for-the-badge&logo=github)](https://github.com/Christopher-Major/Windows-Server-AD-Enterprise-Lab)

A **12-phase enterprise Windows infrastructure lab** designed to simulate the administration and support environment of a small-to-medium organization.

The fictional **Major Technology Services (MTS)** environment was built from initial architecture planning through deployment, administration, troubleshooting, automation, and final validation.

### 🏗️ Environment

- Windows Server 2019
- Windows 11 Enterprise clients
- Hyper-V virtualization
- Active Directory Domain Services (AD DS)
- DNS and DHCP
- Organizational Unit architecture
- Enterprise user and security group management
- Group Policy
- Windows domain workstations
- Departmental SMB file services
- NTFS permissions
- Role-Based Access Control (RBAC)
- AGDLP authorization model
- Administrative workstation
- Delegated administration
- PowerShell automation
- IT support and IAM scenarios

### 🔐 Identity & Access Management

Implemented enterprise-style identity administration including:

- Department-based users and security groups
- Organizational Unit design
- User provisioning
- Account lockout administration
- Password resets
- Department transfers
- User offboarding
- Least-privilege access
- AGDLP group nesting
- Departmental RBAC
- Separate standard and administrative identities
- Delegated DNS, DHCP, and file-server administration

### 🛠️ Administration & Troubleshooting

The project includes documented operational scenarios involving:

- DNS client misconfiguration
- DHCP/DNS dynamic registration
- Group Policy application
- Group Policy drive mappings
- Domain authentication
- File-share authorization
- Account lockouts
- Password resets
- Unauthorized resource access
- Administrative delegation
- Authentication-token/session troubleshooting

Each major issue was documented through **symptoms → diagnosis → remediation → validation**.

### ⚙️ PowerShell Automation

The final phase introduced reusable PowerShell tooling for:

- AD user reporting
- Group membership reporting
- Automated user provisioning
- Department transfers
- User offboarding
- Account health reporting
- Infrastructure health validation
- Administrative logging
- Error handling
- Final environment validation

### 📚 12-Phase Project

1. Planning & Architecture
2. Hyper-V Environment Setup
3. Domain Controller & Active Directory
4. DNS & DHCP
5. Active Directory Organizational Design
6. Users, Groups & IAM
7. File Server & RBAC
8. Domain Workstations
9. Group Policy
10. Validation & Troubleshooting
11. IT Support & IAM Scenarios
12. PowerShell Administration & Automation

**Technologies:** `Windows Server 2019` `Windows 11` `Hyper-V` `Active Directory` `DNS` `DHCP` `Group Policy` `PowerShell` `SMB` `NTFS` `IAM` `RBAC` `AGDLP`
